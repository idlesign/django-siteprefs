# django-siteprefs installation

Python `pip` package is required to install `django-siteprefs`.

## From sources

Use the following command line to install `django-siteprefs` from sources directory (containing `pyproject.toml`):

```shell
pip install .
```

## From PyPI

Alternatively you can install `django-siteprefs` from PyPI:

```shell
pip install django-siteprefs
```

Use `-U` flag for upgrade:

```shell
pip install -U django-siteprefs
```
